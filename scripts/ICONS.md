# Icon sources

All PNGs in `public/icons/` are rendered from `public/icon.svg` (and `public/icon-maskable.svg` for the Android maskable icon) by `npm run icons` (`scripts/icons.mjs`, using sharp).

Both SVGs are original artwork made for Workout Tracker in this repository, following DESIGN-RULES "Icon and imagery": a torn contract pinned to the notice board with a dagger, struck through with a red-ink check. The maskable version is the same picture scaled to 80% so Android's circular crop keeps all of it. No third-party art, fonts or symbols are used.
