# Icon sources

All PNGs in this folder are rendered from `public/icon.svg` by `npm run icons` (`scripts/icons.mjs`, using sharp).

`icon.svg` is original artwork made for Workout Tracker in this repository, following DESIGN-RULES "Icon and imagery": a bone notice with two nails on the board, stamped with a red-ink check. No third-party art, fonts or symbols are used.
